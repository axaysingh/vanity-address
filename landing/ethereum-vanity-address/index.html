Ethereum vanity address generator

Grind a hex 0x… wallet that starts or ends with your word — or a deployer whose first contract hits a vanity address. Same keys work on every EVM chain (Base, Arbitrum, Optimism, Polygon, BNB, …).

Generate in browser Download CLI / desktop

Wallet vanity (EOA)

  1. Open the web generator or CLI.
  2. Choose EVM (evm).
  3. Set hex-friendly prefix / suffix (e.g. dead, cafe).
  4. Import the private key into MetaMask / Rabby.
npx vanity-address --chain evm --prefix dead --suffix cafe

First-deploy contract vanity

Want the contract address to be vanity without a factory? Use evm-contract — grinds a deployer key whose CREATE at nonce 0 matches your pattern.

npx vanity-address --chain evm-contract --prefix cafe

GPU (CLI / desktop)

OpenCL EVM grinding is available with --gpu auto on supported machines (measured on Apple M4; other GPUs untested). Browser WASM stays CPU-only. Candidates are always CPU-reverified before export.

CREATE2 salt vanity

Factory deploys need a salt grind — see the CREATE2 vanity guide.

Hex rules and difficulty

An Ethereum address is 0x plus 40 hex characters, so each fixed character costs a factor of 16 — much cheaper than Base58 chains. A 4-character prefix is trivial, 8 characters takes real compute, and beyond 10 you will want the GPU path.

Frequently asked questions

Which characters can an Ethereum vanity address use?

Only hexadecimal digits: 0–9 and a–f. Words like dead, cafe, face and fade are valid; most English words are not.

Does the same address work on Base, Arbitrum and Optimism?

Yes. EVM chains share the same address format, so one vanity key controls the same address across all of them.

How fast is the GPU path?

On an Apple M4 the OpenCL EVM kernel measured about 46 million keys per second, roughly 90× the CPU on the same machine. NVIDIA and AMD cards are untested.

How long does a 6-character prefix take?

16⁶ ≈ 16.8 million attempts on average — seconds to minutes depending on hardware.
