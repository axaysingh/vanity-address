Bitcoin vanity address generator

Grind a Bitcoin address that includes your word — classic P2PKH (1…), SegWit (bc1q…), or Taproot (bc1p…). Runs locally in the browser, CLI, or desktop app.

Generate in browser Download CLI / desktop

Which Bitcoin format?

  • P2PKH — --chain btc (addresses starting with 1)
  • SegWit — --chain btc-segwit (bc1q…)
  • Taproot — --chain btc-taproot (bc1p…)
npx vanity-address --chain btc-segwit --suffix cafe

Steps

  1. Open the web generator or install the CLI.
  2. Pick Bitcoin / SegWit / Taproot.
  3. Use a short pattern that fits Base58 or bech32.
  4. Import the WIF / key material into Electrum, Sparrow, or your wallet of choice.

Bitcoin-family forks & advanced modes

Same engine covers many P2PKH forks (see project docs). CLI also supports puzzle mode and split-key vanity for Bitcoin-family P2PKH — useful for collaborative grinds without sharing a full private key mid-search.

Alphabet and difficulty by address type

Legacy addresses use Base58 (58 symbols), while SegWit and Taproot use bech32 (32 symbols, excluding 1 b i o). Bech32 patterns therefore cost less per character, but the leading bc1q or bc1p is fixed. Frequently asked questions

Which Bitcoin address types can I customise?

Legacy P2PKH (starts with 1), native SegWit (bc1q…) and Taproot (bc1p…). Each has its own alphabet and fixed leading characters.

Why is a SegWit pattern easier or harder than a legacy one?

SegWit and Taproot use bech32 (32 symbols per position, no 1 b i o), while legacy uses Base58 (58 symbols), so each character costs 32× versus 58×.

Is a vanity Bitcoin address safe?

Yes if the key is generated from a secure random source locally. Avoid online generators that see your key, and verify the address before funding.

Can I use the key in a hardware wallet?

You can import a raw private key into software wallets that support it; most hardware wallets generate their own keys and do not import vanity keys.
