How Stellar addresses work

Stellar public keys are 56-character StrKey strings that start with G, encoded in uppercase RFC 4648 Base32 (A–Z and 2–7).

The alphabet has 32 symbols and no lowercase, so patterns must be uppercase and cannot contain 0 1 8 9.

Alphabet: Base32 (32 symbols per position). Typical shape: G…MOON.

How to generate a Stellar vanity address

  1. Open the web generator or run npx vanity-address.
  2. Choose Stellar (xlm).
  3. Enter a short prefix, suffix, or contains pattern using the Base32 alphabet.
  4. Check the ETA, grind, then verify the result before using it.
npx vanity-address --chain xlm --suffix MOON

Tips for Stellar

  • Suffix words in capitals look best: MOON, STAR, DEFI.
  • A new Stellar account needs a minimum XLM balance to activate on-chain.
  • Export the secret (starting with S) and keep it offline.

Safety

Whoever holds the private key controls the funds. vanity-address creates keys locally from your operating system's secure random source and re-derives every address on the CPU before export. The exported file is a plaintext secret: keep it offline and never commit or email it. Read the security model before moving significant value.
