Solana vanity address generator

Create a real Solana wallet (or SPL token mint) whose address starts with, ends with, or contains your word — entirely on your machine. No accounts. No telemetry.

Generate in browser Download CLI / desktop

How to grind a Solana vanity wallet

  1. Open the web generator (or run npx vanity-address).
  2. Pick Solana (sol).
  3. Set a short prefix, suffix, or contains pattern (Base58 alphabet).
  4. Check the ETA, then grind. Import the key into Phantom / Solflare like any other wallet.
npx vanity-address --chain sol --suffix moon

Solana token mint vanity

Need a mint that ends in something like pump? Use Contract mode → Solana mint, or CLI --chain sol-mint. Export is ready for spl-token create-token.

npx vanity-address --chain sol-mint --suffix cafe

Why offline matters

Anyone with the private key controls the funds. vanity-address generates keys only on your device. Prefer short patterns first — each extra character multiplies grind time.
