How to grind a Solana vanity wallet

  1. Open the web generator (or run npx vanity-address).
  2. Pick Solana (sol).
  3. Set a short prefix, suffix, or contains pattern (Base58 alphabet).
  4. Check the ETA, then grind. Import the key into Phantom / Solflare like any other wallet.
npx vanity-address --chain sol --suffix moon

Solana token mint vanity

Need a mint that ends in something like pump? Use Contract mode → Solana mint, or CLI --chain sol-mint. Export is ready for spl-token create-token.

npx vanity-address --chain sol-mint --suffix cafe

Why offline matters

Anyone with the private key controls the funds. vanity-address generates keys only on your device. Prefer short patterns first — each extra character multiplies grind time.

Base58 rules and difficulty

Solana public keys are Base58-encoded 32-byte Ed25519 keys, typically 43–44 characters long. Because the alphabet has 58 symbols, every extra character you fix multiplies the expected work by about 58. Matching case-insensitively roughly halves the cost of each letter, since both a and A count.

Frequently asked questions

Which characters can a Solana vanity address contain?

Solana addresses are Base58, so patterns can use letters and digits except 0, O, I and l.

Can I import the generated key into Phantom or Solflare?

Yes. Export the key in the format the wallet asks for and import it like any other private key. Verify the public address matches before funding.

Is the GPU faster for Solana?

Not currently. The experimental OpenCL Solana kernel is slower than the CPU, so the CPU path is used by default; GPU speed-ups are measured on EVM only.

How long does a 5-character Solana suffix take?

About 58⁵ ≈ 656 million attempts on average when case-sensitive; ignoring case lowers this for letters.
