How TON addresses work

TON user-friendly addresses are 48-character base64url strings. The first two characters encode flags and workchain, and the third character can only be one of A–D for workchain 0, so only part of the front of the address is free.

vanity-address computes the Wallet V4R2 address from the public key and the contract code hash, then CRC-checks the result before showing it.

Alphabet: Base64url (64 symbols per position). Typical shape: UQ….

How to generate a TON vanity address

  1. Open the web generator or run npx vanity-address.
  2. Choose TON (ton).
  3. Enter a short prefix, suffix, or contains pattern using the Base64url alphabet.
  4. Check the ETA, grind, then verify the result before using it.
npx vanity-address --chain ton --suffix moon

Tips for TON

  • Suffix patterns are the most flexible on TON because the end of the address is fully random.
  • The base64url alphabet allows A–Z a–z 0–9 _ - and is case-sensitive.
  • Import the exported key into a wallet that supports V4R2 to get the same address.

Safety

Whoever holds the private key controls the funds. vanity-address creates keys locally from your operating system's secure random source and re-derives every address on the CPU before export. The exported file is a plaintext secret: keep it offline and never commit or email it. Read the security model before moving significant value.

Frequently asked questions

Why can't I set the first characters of a TON address?

They carry address flags and workchain, so only certain values are valid. The tool accounts for those fixed bits when estimating difficulty.

How many attempts does a 4-character TON suffix need?

About 64⁴ ≈ 16.8 million on average.
