How NEAR addresses work

NEAR implicit accounts are the 64-character lowercase hex encoding of an Ed25519 public key. Because the account ID is the key, you can fund it before ever creating it on-chain.

Patterns are limited to 0–9 and a–f. Named accounts such as alice.near are registered on-chain and cannot be ground.

Alphabet: Hex (16 symbols per position). Typical shape: cafe….

How to generate a NEAR vanity address

  1. Open the web generator or run npx vanity-address.
  2. Choose NEAR (near).
  3. Enter a short prefix, suffix, or contains pattern using the Hex alphabet.
  4. Check the ETA, grind, then verify the result before using it.
npx vanity-address --chain near --suffix cafe

Tips for NEAR

  • Short hex words like dead or cafe take seconds.
  • Each extra hex character multiplies the work by 16 — one more character is 16× slower.
  • Back up the exported key before sending funds to the account.

Safety

Whoever holds the private key controls the funds. vanity-address creates keys locally from your operating system's secure random source and re-derives every address on the CPU before export. The exported file is a plaintext secret: keep it offline and never commit or email it. Read the security model before moving significant value.
