How XRP Ledger addresses work

XRP classic addresses start with r and use the Ripple Base58 alphabet, which is ordered differently from Bitcoin's. It omits 0 O I l and also the uppercase letters A C F.

vanity-address uses the Ripple alphabet when checking patterns, so a pattern that is valid for Bitcoin may be impossible on XRP.

Alphabet: Ripple Base58 (58 symbols per position). Typical shape: rMoon….

How to generate a XRP Ledger vanity address

  1. Open the web generator or run npx vanity-address.
  2. Choose XRP Ledger (xrp).
  3. Enter a short prefix, suffix, or contains pattern using the Ripple Base58 alphabet.
  4. Check the ETA, grind, then verify the result before using it.
npx vanity-address --chain xrp --suffix moon

Tips for XRP Ledger

  • Lowercase words usually work well — moon, rich, dao.
  • Confirm results on XRPSCAN or in any wallet that imports family seeds before funding.
  • Remember the XRP Ledger reserve requirement when activating a new address.

Safety

Whoever holds the private key controls the funds. vanity-address creates keys locally from your operating system's secure random source and re-derives every address on the CPU before export. The exported file is a plaintext secret: keep it offline and never commit or email it. Read the security model before moving significant value.

Frequently asked questions

Why is my XRP pattern rejected?

It likely contains a character outside the Ripple alphabet, such as 0, O, I, l, A, C or F.

Do XRP addresses always start with r?

Yes, classic addresses begin with r.
