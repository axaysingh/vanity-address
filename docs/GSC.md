# Google Search Console

Canonical site: **https://vanity-address.online/**

`landing/_worker.js` 301s `www.vanity-address.online` → apex and returns a real `404` for unknown paths.

## 1. Add / verify property

Prefer a **Domain** property (DNS TXT) for `vanity-address.online` — covers `http` / `https` / `www` without an HTML meta tag.

1. Open [Google Search Console](https://search.google.com/search-console)
2. **Add property** → **Domain** → `vanity-address.online`
3. Add the TXT record at your DNS (Cloudflare DNS for this domain)
4. Click **Verify**

## 2. Submit sitemap

1. Search Console → **Sitemaps**
2. Submit: `https://vanity-address.online/sitemap.xml`
3. Expect **19** HTML URLs (home, `/generate/`, `/chains/`, difficulty calculator, 15 chain/CREATE2 guides).  
   `llms.txt` and `how-to-generate-vanity-address.md` are linked from the site but are **not** in the sitemap (by design).

## 3. Request indexing (first wave)

URL Inspection → **Request indexing** for:

- `https://vanity-address.online/`
- `https://vanity-address.online/generate/`
- `https://vanity-address.online/chains/`
- `https://vanity-address.online/vanity-address-difficulty/`
- `https://vanity-address.online/solana-vanity-address/`
- `https://vanity-address.online/ethereum-vanity-address/`
- `https://vanity-address.online/bitcoin-vanity-address/`
- `https://vanity-address.online/tron-vanity-address/`

Re-index after real content changes; do not spam requests.

## 4. Smoke checks after deploy

```bash
# www must 301 to apex (same path)
curl -sI https://www.vanity-address.online/generate/ | grep -i location
# → Location: https://vanity-address.online/generate/

# Unknown path must be real 404 (not homepage 200)
curl -sI https://vanity-address.online/this-does-not-exist-seo/ | head -1
# → HTTP/2 404
```
